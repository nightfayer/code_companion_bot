# 🕵️‍♂️ QA Manual Companion (Telegram Bot)

Персональный AI-ментор и рабочий инструмент для начинающего специалиста по ручному тестированию (**Manual QA**) на базе **aiogram 3**, персистентной базы **SQLite** (`aiosqlite`) и нейросети **NVIDIA Nemotron 120B** (`nvidia/nemotron-3-super-120b-a12b`).

Бот помогает освоить профессию QA с нуля, проектировать тест-кейсы и чек-листы, оформлять идеальные баг-репорты по стандарту Jira / YouTrack, рассчитывать граничные значения (BVA), генерировать тестовые данные (включая XSS/SQLi) и экспортировать тест-кейсы в готовый `.csv` файл для **TestRail** и **Qase TMS**.

---

## 🚀 Ключевые возможности

### 1. 🧑‍🏫 Три специализированных режима работы (`/mode`):
- 🟢 **🧑‍🏫 QA Ментор (по умолчанию):** Понятно объясняет теорию тестирования (ISTQB, жизненный цикл бага, уровни и виды тестирования, Client-Server, HTTP-методы, DevTools, снифферы, SQL для QA) и готовит к собеседованиям на Junior QA.
- 🔴 **🔍 Bug Hunter (Охотник за багами):** Эксперт по исследовательскому тестированию. Находит коварные корнер-кейсы, негативные сценарии, инъекции, проблемы concurrency и падения при обрыве сети.
- 🔵 **⚡ Fast QA Tool (Быстрый генератор):** Мгновенная генерация структурированных чек-листов, классов эквивалентности и баг-репортов без лишних предисловий.

### 2. 📋 Анализ любого объекта тестирования в 1 клик:
Отправьте боту описание фичи, ТЗ, форму, JSON или прикрепите файл (`.txt`, `.md`, `.json`, `.csv`, `.sql`, `.html`):
- 📋 **Тест-кейсы / Чек-лист** — позитивные (Happy Path), негативные, граничные проверки и безопасность со структурой (ID, Title, Preconditions, Steps, Expected Result).
- 🐛 **Баг-репорт (Jira)** — оформление по правилу «Что? Где? При каких условиях?», с указанием Severity/Priority, шагов, Actual и Expected Result.
- 🎲 **Тестовые данные** — спецсимволы, XSS/SQLi строки, переполнения, пустые значения, эмодзи, готовый JSON Payload.
- ⚠️ **Граничные значения (BVA)** — таблицы классов эквивалентности и границ (Min-1, Min, Min+1, Max-1, Max, Max+1).
- 🔍 **Анализ ТЗ и рисков** — выявление «белых пятен» и вопросов к аналитикам до релиза.
- 📥 **Скачивание CSV для TestRail** — готовый скачиваемый файл с разделителями для импорта в TMS.

### 3. 🎨 Telegram Bot API 9.4 & 10.1 (Rich Messages):
- **Нативная блочная вёрстка (Bot API 10.1):** нативные блоки и таблицы с рамками.
- **Настоящие цветные кнопки (Bot API 9.4+):** визуальное разделение действий (`style="success"`, `"danger"`, `"primary"`).
- **Нативный блок размышлений (`InputRichBlockThinking`):** прозрачный статус рассуждений AI.
- **Сворачиваемые цитаты (`<blockquote expandable>`):** для объемных лонгов и рассуждений.
- **Реакции бота (`react`):** живые реакции на сообщения.

### 4. 💬 Inline Mode (Вызов в любом чате с коллегами):
Наберите `@имя_бота` в любом чате или группе:
- **Шпаргалка: HTTP-коды ответов API** (200, 201, 204, 400, 401, 403, 404, 422, 500, 502).
- **Шаблон идеального баг-репорта** (Jira / YouTrack стандарт).
- **Шпаргалка: Тест-дизайн (BVA & EP)** с наглядным примером диапазона возраста.
- Или введите любой вопрос (например, `@имя_бота как протестировать корзину`) и отправьте готовый структурированный ответ прямо в чат!

### 5. 🧠 Постоянная память и SQLite:
- Настройки режима пользователя и история диалогов сохраняются в локальной базе `bot.db`.
- Очистить контекст можно командой `/clear`.

## 🛠 Быстрый запуск

### 1. Установка зависимостей
```bash
python -m venv venv
venv\Scripts\activate  # Для Windows
pip install -r requirements.txt
```

### 2. Настройка `.env`
Создайте файл `.env` на основе `.env.example`:
```env
BOT_TOKEN=ваш_токен_от_BotFather
NVIDIA_API_KEY=ваш_ключ_NVIDIA_NIM
TELEGRAM_PROXY=http://127.0.0.1:10809  # Опционально (при блокировках провайдеров)
```

### 3. Включение Inline Mode в BotFather
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/setinline`.
3. Выберите вашего бота.
4. Введите текст-плейсхолдер: `Спросить QA Ментора о тестировании или ТЗ...`

### 4. Запуск бота
- На Windows: дважды кликните `run.bat` или выполните:
```bash
python bot.py
```
