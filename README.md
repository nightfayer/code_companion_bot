# 🤖 Senior AI Code Companion (Telegram Bot)

Умный напарник разработчика на базе **aiogram 3**, архитектуры **SQLite** (`aiosqlite`) и нейросети **NVIDIA Nemotron 120B** (`nvidia/nemotron-3-super-120b-a12b`).

Бот умеет проводить детальный аудит кода, оценивать алгоритмическую сложность $O(N)$, выполнять SOLID-рефакторинг с визуальным Git Diff, автоматически генерировать готовые Unit-тесты и работать в **Inline-режиме** прямо в чатах с коллегами.

---

## 🚀 Ключевые возможности

1. **🧠 Постоянная память диалога (SQLite):**
   - Бот помнит историю общения и контекст даже после перезапуска сервера.
   - Очистить контекст можно командой `/clear`.

2. **⚡ Непрерывный статус «Печатает...» (`ChatActionSender`):**
   - Анимация ввода текста активна каждую секунду, пока нейросеть формирует ответ.

3. **🎨 Telegram Bot API 9.4:**
   - **Цветные кнопки (`style="danger"`, `"success"`, `"primary"`):** визуальное выделение действий по последнему стандарту Telegram.
   - **Сворачиваемые цитаты (`<blockquote expandable>`):** логи мышления скрыты под аккуратным спойлером.
   - **Реакции бота (`react`):** живой фидбек эмодзи на сообщения пользователя.

4. **🧪 Скачивание готовых файлов в 1 клик:**
   - При запросе тестов или рефакторинга бот отправляет в чат настоящий файл (`test_module.py`, `refactored_code.py`), готовый к запуску.

5. **📊 Визуальный Git Diff («Было / Стало»):**
   - Интерактивная подсветка добавленных (`+`) и удаленных (`-`) строк кода с помощью модуля `difflib` и синтаксиса `diff`.

6. **💬 Inline Mode (Вызов в любом чате):**
   - Наберите в любом чате или канале `@имя_бота <вопрос>`:
     - Без запроса — удобные карточки шпаргалок ($O(N)$, Singleton, SOLID).
     - С запросом — быстрый разбор вопроса или сниппет от AI для отправки собеседнику.

## 🛠 Быстрый запуск

### 1. Установка зависимостей
```bash
python -m venv venv
venv\Scripts\activate  # Для Windows
pip install -r requirements.txt
```

### 2. Настройка `.env`
Создайте файл `.env` на основе `.env.example`:
```env
BOT_TOKEN=ваш_токен_от_BotFather
NVIDIA_API_KEY=ваш_ключ_NVIDIA_NIM
TELEGRAM_PROXY=http://127.0.0.1:10809  # Опционально (при блокировках)
```

### 3. Включение Inline Mode в BotFather
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/setinline`.
3. Выберите вашего бота.
4. Введите текст-плейсхолдер, например: `Спросить AI о коде или алгоритме...`

### 4. Запуск
- На Windows: запустите `run.bat` или:
```bash
python bot.py
```
